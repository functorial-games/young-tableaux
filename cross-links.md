# Cross-links

This repository is the interaction/combinatorics side. Keep historical/source-heavy work in the repositories where it already belongs and link across rather than duplicating it.

## Existing related repositories

### walnut-burgundy/fulton

https://github.com/walnut-burgundy/fulton

The Fulton repository is explicitly a reading/synthesis repository around William Fulton, including Young tableaux, representation theory, symmetric functions and geometry.

Useful overlap:
- William Fulton's Young Tableaux;
- Bruce Sagan's The Symmetric Group;
- Schur functions;
- representation theory;
- Grassmannians / flag varieties / Schubert calculus.

Rule of thumb:
- source history, attribution, bibliographic tracing, and book-centered synthesis -> walnut-burgundy/fulton
- executable/interactive mathematical object and experiments -> functorial-games/young-tableaux

Cross-link both ways when one side develops material the other can use.

### isomorphismes/coxeter

https://github.com/isomorphismes/coxeter

Type A Coxeter groups are symmetric groups. The Coxeter repository already works with:
- simple reflections / adjacent transpositions;
- reduced words;
- weak/Bruhat-type structure;
- exact permutation representations;
- Coxeter length.

Potential bridges:
- permutation <-> RSK shape/tableaux;
- reduced words and tableau-related combinatorics;
- weak/Bruhat order vs Young-lattice order (distinct structures: do not conflate them);
- parabolic subgroups / Young subgroups;
- noncrossing partitions in type A;
- Hecke algebra extensions.

## External subject bridges worth preserving

- Symmetric functions connect tableaux to representation theory and algebraic geometry.
- Schur–Weyl duality connects S_n and GL_d.
- Littlewood–Richardson coefficients connect tableau counting, tensor/product rules and Schubert intersection numbers.
- RSK connects permutations/words/matrices to tableaux, longest increasing subsequences and random-matrix asymptotics.
- Young's lattice connects standard tableaux to paths and the branching rule.
- Fomin growth diagrams connect RSK-like global bijections to local rules.
- Plancherel measure connects irreducible dimensions to random Young diagrams.
- Coxeter type A supplies a second structural language for the same symmetric groups without making tableaux and Coxeter words the same object.
